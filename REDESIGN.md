# ЗАДАЧА: полный редизайн pocketosix (лендинг + /run + терминал)

Ты работаешь над open-source проектом **pocketosix**: настоящий Alpine userspace, Xorg и i3 в браузере, на CheerpX, с локальным диском (IndexedDB) и опциональным Tailscale. Next.js отвечает только за оболочку, гостевая система исполняется на устройстве пользователя.

Сейчас сайт выглядит как мягкая бежевая SaaS-страница с зелёным скруглённым квадратом «p_». **Это нужно полностью заменить.** Цель: проект должен выглядеть как работа очень сильного инженера-дизайнера. Он должен быть пригоден для портфолио, для Hacker News / Product Hunt и для GitHub-README.

## 0. Порядок работы
1. Сначала прочитай репозиторий. Найди, где живёт логика CheerpX (инициализация, `setKmsCanvas`, диск, Tailscale, проверка браузера). **Не меняй эту логику без необходимости**, перепиши только UI вокруг неё.
2. Выдай короткий план: какие файлы меняешь, какие компоненты создаёшь.
3. Реализуй по этапам: (a) дизайн-токены и логотип, (b) `/run`, (c) терминал, (d) лендинг, (e) полировка, доступность, README.
4. После каждого этапа проверяй, что `/run` по-прежнему загружает и запускает систему.

## 1. Главная идея
**Сайт сам устроен как тайловый оконный менеджер i3.**
- Всё состоит из «окон-тайлов» с зазором ровно **8px** и рамкой **1px**.
- Активное окно подсвечено градиентной рамкой из логотипа, остальные приглушены.
- Секции лендинга выглядят как **воркспейсы**: `1:what 2:how 3:limits 4:run`.
- Внизу вместо футера стоит **i3bar-статусбар** с реальными данными.
- Лендинг и продукт выглядят как одно целое.

Тон: честный, технический, с сухим юмором. Никакого маркетингового мусора и никаких выдуманных цифр. Все метрики, которые показываются на сайте, должны быть реальными.

Сделай компонент `<Logo variant="full | mark | mono" />`:
- `mark`: только шестиугольник.
- `full`: шестиугольник и слово `pocketosix` моноширинным шрифтом, `letter-spacing: -0.02em`, без точки в конце.
- `mono`: одноцветная версия через `currentColor`, для favicon, README и мелких размеров.

Сгенерируй: `favicon.svg`, `apple-touch-icon.png` (180), `og-image.png` (1200×630, тёмный фон, большой логотип, слоган), `manifest.webmanifest`. Шестиугольник в хедере слегка «оживает» при hover: курсор `_` мигает, неактивные тайлы чуть светлеют.

## 3. Дизайн-система

### Цвета (тёмная тема по умолчанию, CSS variables)
```css
:root{
  --bg:        #07090D;  /* фон страницы */
  --surface:   #0D1117;  /* тайл */
  --surface-2: #121821;  /* поднятый тайл, hover */
  --border:    #1E2733;  /* неактивная рамка */
  --border-hi: #2B3848;
  --text:      #E6EDF3;
  --muted:     #8B98A9;
  --faint:     #5B6778;

  --teal:   #5EEAD4;
  --blue:   #3B82F6;
  --cyan:   #22D3EE;
  --indigo: #6366F1;
  --warn:   #F5B544;
  --danger: #F87171;

  --grad: linear-gradient(135deg, #5EEAD4, #3B82F6);
  --gap: 8px;
  --radius: 6px;          /* максимум. Это тайлы, а не «таблетки» */
}
```
- Светлая тема опциональна. Если делаешь, то на тех же токенах и без бежевого. Тёмная остаётся основной.
- Градиент используется экономно: активная рамка, главная кнопка, ключевой акцент в заголовке. Не заливай им большие площади.
- Никаких больших скруглений, мягких теней и стеклянных блюров. Глубина создаётся рамками, тонкой сеткой точек и редкими свечениями (`box-shadow: 0 0 0 1px` плюс слабый glow teal только у активного тайла).

### Типографика
- Моно: **Geist Mono** или **JetBrains Mono** (через `next/font`). Это основной шрифт интерфейса, подписей, цифр, кнопок и статусбара.
- Заголовки: **Geist** или **Inter Tight**, 600–700, `letter-spacing: -0.03em`, крупные (`clamp(2.5rem, 7vw, 6rem)`).
- Мелкие подписи: моно, uppercase, `letter-spacing: 0.08em`, 11–12px, цвет `--muted`.
- Цифры всегда `font-variant-numeric: tabular-nums`.

### Компоненты
- **Tile** (базовое окно): `background: var(--surface)`, `border: 1px solid var(--border)`, `radius: var(--radius)`. Вариант `active` с градиентной рамкой (через `background-clip` или mask), вариант `dim` с `opacity: .6`. Внутри тонкий заголовок окна как в i3: `[ title ]` слева, номер или метка справа.
- **Button**: primary (градиентная заливка, тёмный текст, моно, префикс `>`), secondary (рамка), ghost. Фокус-ринг 2px teal. Высота 36/44.
- **Kbd**: плашка с клавишей, для подсказок.
- **StatusDot**, **Badge**, **Tooltip**, **Dropdown**, **Dialog** (подтверждения вроде сброса диска).
- **AsciiProgress**: `[██████░░░░] 62%`.
- **I3Bar**: нижняя полоса, 28–32px, моно. Слева воркспейсы-кнопки `[1:what]`, активный подсвечен инверсией или градиентом. Справа статусы и время.
- Иконки: единый набор (lucide), stroke 1.5, без эмодзи в интерфейсе.

### Движение
- Быстро и чётко: 120–180ms, `cubic-bezier(.2,.8,.2,1)`. Переключение воркспейса: тайлы «пересобираются» (короткий slide и fade), как в i3.
- Курсор `_` мигает ступенчато (`steps(1)`).
- Обязательно уважай `prefers-reduced-motion`: отключи всё декоративное.

## 4. Страница `/` (лендинг)

Структура. Каждая секция это «воркспейс» на всю высоту экрана. Прокрутка и клавиши `1..4` (без модификаторов, только когда фокус не в поле ввода) переключают их. Состояние отражено в I3Bar.

### Hero (workspace 1:what)
- Центр: **3D-шестигранная призма**, грани которой повторяют тайлы логотипа (teal/blue большой тайл, indigo полупрозрачный, cyan активный). На одной грани мигает `_`.
- Поверх призмы **ASCII/dither-постобработка** (WebGL, один fullscreen-quad или react-three-fiber + postprocessing). Яркость превращается в упорядоченный Bayer 4×4 dither или в символы ` .:-=+*#%@`, палитра teal→blue.
- Курсор работает как источник света: вокруг него картинка «проявляется» из ASCII в чистый рендер. Призма медленно вращается и слегка наклоняется за курсором.
- Fallback: если `prefers-reduced-motion`, нет WebGL2, слабое устройство или ширина < 640px, показывай статичный dither-кадр (PNG/SVG). Шейдер не должен тормозить: DPR cap 1.5, пауза вне viewport (IntersectionObserver).
- Заголовок:
  ```
  real unix vibe
  right in your browser.
  ```
  Вторая строка использует градиент `--grad` как текст. Подзаголовок (RU) «Настоящий Alpine, Xorg и i3. Всё считается на твоём устройстве. Файлы остаются у тебя.»
- Кнопки: `[ > launch ]` (primary, ведёт на `/run`) и `[ how it works ]` (скролл к воркспейсу 2).
- Строка фактов моно: `alpine · xorg · i3 · 0 servers`.
- **Честный boot-лог** (реально печатается при загрузке страницы, в моно, в маленьком тайле):
  ```
  [ ok ] cheerpx sdk found
  [ ok ] syscall layer: x86-32 -> wasm
  [warn] no linux kernel found. none needed.
  [ ok ] alpine userspace ready to mount
  ```
  Строки `ok` брать из реальной проверки возможностей браузера, не из заглушек.

### 2:how
Горизонтальная схема с бегущими «пакетами» (анимированный SVG):
`browser → Next.js shell → CheerpX (x86 → wasm) → Alpine → Xorg → <canvas>`
Под ней одна фраза: «Код выполняется у тебя, а не на сервере». Три i3-тайла: **Alpine userspace**, **Xorg + i3**, **CheerpX**. Внутри настоящие скриншоты или короткие видео (`<video muted loop playsinline>`), а не рисунки. Если их пока нет, оставь плейсхолдеры с TODO.

### 3:limits (блок «чего здесь нет»)
Тайл в стиле warning (рамка `--warn`, заголовок `[warn]`). Честно и без смягчений:
- нет настоящего Linux kernel (CheerpX даёт совместимость syscalls для 32-bit x86 userspace);
- это не Docker, не systemd-среда и не аппаратная VM;
- часть syscalls и приложений может не работать.

Рядом карточки **Local persistent disk** (IndexedDB, можно экспортировать) и **Tailscale** (опционально, статусы `off / connecting / online`).

### 4:run (финал)
Большая шестигранная кнопка `launch`, ссылки на GitHub, лицензию и документацию. Бейджи GitHub stars, license, last commit (статично или через API с кэшем).

### Хедер лендинга
Тонкий и без мишуры: `Logo full` слева, справа ссылки `docs`, `github`, переключатель языка RU/EN, индикатор `● client-side`.

## 5. Страница `/run`

### Шаг 0: preflight
- Сохрани существующие проверки (SharedArrayBuffer, WebAssembly, IndexedDB), но оформи их как **boot-лог в моно**, а не как список со спиннером.
- Загрузка CheerpX и образа начинается **только после клика** `[ > boot ]` (нужен user gesture). До клика покажи: сколько МБ скачается, закэшировано ли уже, чекбокс «включить сеть (Tailscale)».
- Прогресс: `AsciiProgress` и текущий этап. Ошибки показывай честно: причина (например, нет cross-origin isolation) и что делать.
- Убери слоган «YOUR MACHINE. YOUR SPACE.» и бежевый фон.

### Основной режим (по умолчанию): окно в странице
Раскладка тайлами с зазором 8px:
```
┌ topbar: [hex] pocketosix   alpine / i3   ● running          ? ┐
├───────────────────────────────────────────┬────────────────────┤
│                                           │ SYSTEM             │
│                                           │ status  running    │
│          Xorg canvas (active tile,        │ boot    4.2s       │
│          градиентная рамка)               │ fps     60         │
│                                           │ disk    38 MB      │
│                                           │ net     off        │
│                                           ├────────────────────┤
│                                           │ [⛶ fullscreen]     │
│                                           │ [⌨ keys] [paste]   │
│                                           │ [💾 export][import]│
│                                           │ [↺ reset disk]     │
├───────────────────────────────────────────┴────────────────────┤
│ [ terminal ]  (докируемый тайл, см. раздел 6)                  │
├────────────────────────────────────────────────────────────────┤
│ i3bar: [1:desktop][2:disk][3:network][4:help]   cpu · disk · 14:02│
└────────────────────────────────────────────────────────────────┘
```
- Боковая панель сворачивается (ширина 280 → 0), canvas растягивается. Состояние запоминается в localStorage.
- Canvas сохраняет соотношение сторон и режим масштабирования: `fit` или `1:1`. Переключатель в панели.
- Кнопки панели: fullscreen, отправка комбинаций (`Ctrl+Alt+Del`, `Super`, `Alt+Tab`), вставка из буфера обмена, экспорт и импорт диска, сброс диска (через Dialog с подтверждением и явным описанием последствий), сеть (Tailscale on/off, статус, IP), справка.
- **Только реальные метрики.** Boot time, FPS (из `requestAnimationFrame` на canvas), размер IndexedDB (`navigator.storage.estimate()`). Если значение недоступно, показывай `—`, а не выдумывай.
- Старая вторая панель («Подключить сеть», иконки диска, терминала, fullscreen, «Как пользоваться») переезжает в topbar и боковую панель в новом стиле.

### Focus mode (fullscreen)
Всё скрыто, виден только рабочий стол. У края экрана лежит маленькая полупрозрачная **шестигранная кнопка** (логотип mark), по клику выезжает та же панель поверх canvas. Выход: **удержание `Esc` 600ms** с кольцевым индикатором, потому что обычный `Esc` нужен гостевой системе. Первый раз покажи подсказку на 3 секунды.

### Ввод
- Когда фокус на canvas, **все клавиши уходят в гостя**, глобальные хоткеи сайта не срабатывают. Хост-хоткеи только при фокусе вне canvas.
- Явная индикация фокуса: рамка canvas становится градиентной, иначе тусклой. В I3Bar `input: guest | host`.
- Pointer lock как опция.

### Мобильные
- Нижняя панель клавиш, которых нет на экранной клавиатуре: `Esc Ctrl Alt Tab ↑ ↓ ← → | ~ /`, залипающие модификаторы.
- Если устройство слабое или браузер не поддерживается, покажи честное предупреждение с причиной и кнопкой «всё равно запустить».

## 6. Терминал в окошке
- Это **настоящий терминал, подключённый к гостевому shell** через API CheerpX (консоль/`setConsole` или эквивалент, смотри актуальный SDK). Никаких заранее заготовленных ответов и никакой имитации.
- UI: xterm.js (если уже используется, сохрани) в тайле, который можно **докировать снизу или справа, скрыть и растянуть** (перетаскивание разделителя 8px). Заголовок тайла `[ terminal · sh ]` и кнопки: clear, copy, fullscreen-tile, close.
- Тема терминала на токенах: фон `--bg`, текст `--text`, курсор `--teal`, ANSI-палитра на основе teal/blue/cyan/indigo/warn/danger.
- Горячая клавиша открытия работает только при фокусе вне canvas, плюс кнопка `>_` в topbar.
- Если терминал в данной конфигурации технически недоступен до загрузки системы, показывай disabled-состояние с пояснением, не пустой чёрный прямоугольник.

## 7. Статусбар (I3Bar) на всех страницах
Моно, 28–32px, фон `--surface`, верхняя рамка 1px.
- Слева воркспейсы, активный подсвечен.
- Справа: `● alpine`, `cpu idle|busy`, `disk local · 38MB`, `net off|online`, время.

## 8. Тексты
- Двуязычность: RU и EN через простой i18n (словарь). Язык по `navigator.language`, переключатель в хедере. Технические термины не переводить.
- Убери пафос и клише («Ваш Linux. В вашем браузере.» можно оставить как RU-версию главного слогана, но в стиле нового дизайна). Оговорку «нет настоящего ядра» не прячь и не смягчай.

## 9. Технические требования
- Next.js (текущая версия проекта), TypeScript, без тяжёлых UI-библиотек. Допустимо: Tailwind (если уже есть), `next/font`, lucide, three/r3f только на лендинге и только dynamic import.
- **CheerpX грузить только на `/run`.** Лендинг не должен тянуть SDK.
- COOP/COEP заголовки для `/run` должны остаться рабочими. Проверь, что лендинг не сломан ими (ресурсы с `crossorigin`).
- Lighthouse лендинга: Performance ≥ 90 на десктопе, CLS < 0.05. Тяжёлый шейдер не блокирует LCP (заголовок виден сразу).
- Доступность: контраст AA, видимый focus, полное управление с клавиатуры, `aria-label` у иконок-кнопок, `aria-live` для статуса загрузки, корректные роли у Dialog и Dropdown.
- Никаких внешних трекеров. Нигде не пиши «no tracking», если это не проверено.
